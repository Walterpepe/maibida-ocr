Software Features

• Full touchscreen control with simple operation and inspection times as fast as 0.03 seconds, depending on ROI settings;

•  Adjust ROI sensitivity independently with no fixed limit on the number of ROIs.

•  AI-assisted image acquisition and automatic capture timing;

•  Supports rectangular, elliptical and free-form inspection regions for complex molds.

•  Set sensitivity and inspection area independently for each region.

•  Configure I/O outputs in the inspection logic to match application requirements.

•  Add reference images manually and perform static reference-image learning from the sensitivity settings page.

•  Automatic brightness correction reduces false alarms caused by changes in ambient light.

•  Set separate user passwords for parameter configuration, template editing and algorithm settings to prevent unauthorized changes.

•  Alarm images retain configuration data and I/O output status; reports can be exported to a USB drive with one click.  


Hardware Advantages

• Compact and easy to handle, with five Ethernet ports for additional cameras and a reserved MES integration interface;

•  Supports cameras up to 8 MP with integrated infrared and white dual lighting and monochrome or color modes. The built-in 12× autofocus lens and in-house depth-of-field integration improve setup speed and image consistency;

•  I/O inputs: independent channels for flexible, convenient wiring;

•  I/O outputs: six outputs including external alarm, cycle start and ejector re-stroke interfaces;

•  Internally isolated I/O relays connect directly to the customer load circuit;

•  An optional SD card stores images and supports program upgrades and I/O logic configuration updates.

•  Multiple mounting options are available for different production environments.
